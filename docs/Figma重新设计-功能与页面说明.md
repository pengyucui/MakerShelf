# MakerShelf · 发给 Figma 的功能与页面说明

> 用途：把当前 **macOS 原生应用已经实现的功能** 交给 Figma 重新设计全部页面。  
> 请按本文设计，不要按旧网页方案 A/B/C 的独立详情弹窗、心形收藏或「同步收藏 / 新增下载」双按钮。  
> 产品语言：简体中文。平台：**macOS 14+ 桌面应用**（不是 iPhone / 不是网站）。

---

## 1. 给设计师的一句话

MakerShelf 是「MakerWorld 本地模型馆」：用户把中文站、国际站的模型和自己电脑里的 3MF/STL 归档到本机，离线翻封面、介绍和文件，再拿去切片打印。

用户首先看到的是 **作品卡片**，不是文件夹。

## 2. 产品边界（设计时必须遵守）

| 要做 | 不要做 |
| --- | --- |
| 本地浏览、导入、下载、编辑已归档模型 | 不改 MakerWorld 网站上的收藏 |
| 中文站、国际站两套独立账号 | 不把两站账号画成同一个登录 |
| 一个主按钮「导入模型」 | 不要同时放「同步收藏」和「新增下载」 |
| 详情在右侧 Inspector，选中卡片不离开网格 | 不要再做覆盖全窗的大型详情弹窗 |
| 登录用系统独立窗口打开官网登录页 | 不要在主窗口里嵌网页登录 |
| 归档永远包含：模型文件 + 介绍 + 图片 | 不要做「只下图片 / 只下介绍」开关 |
| 浅色 / 深色跟随系统 | 不要做成深色-only 控制台 |

**不在本轮设计范围：** 三维预览、云同步、作者订阅/自动追更、自定义收藏夹、重复文件清理、iPhone/iPad 版。

## 4. 信息架构

```text
MakerShelf
├── 侧栏（常驻）
│   ├── 品牌：MakerShelf / 本地模型馆
│   ├── 工作空间
│   │   ├── 模型库        显示全部模型数
│   │   ├── 下载任务      有未完成任务时显示数字
│   │   └── 设置
│   ├── 来源（可点击筛选模型库）
│   │   ├── 中文站        连接状态或用户名
│   │   ├── 国际站        连接状态或用户名
│   │   └── 本地模型      N 个模型
│   └── 本地资料库卡片    已占用空间
│
├── 工具栏（随当前页变化）
│   ├── 左侧：当前页名称 + 一句副标题
│   ├── 模型库时：搜索框 ⌘K
│   ├── 模型库 / 下载任务：主按钮「导入模型」
│   └── ⋯ 菜单：设置、版本号
│
└── 内容区
    ├── 模型库 = 左网格/列表 + 右 Inspector
    ├── 下载任务 = 指标 + 队列
    └── 设置 = 站点账号 | 存储与下载
```

**唯一主操作：导入模型（⌘N）**  
三个来源共用一个居中 Sheet：用户主页 / 模型链接 / 本地模型。

## 6. 页面说明

### 6.1 模型库（默认首页）

**目标：** 快速找到已经归档或待下载的模型，点选后在右侧看详情。

**布局：**

```text
┌ 工具栏：模型库 · N 个模型 | 搜索 | 导入模型 | ⋯ ┐
┌ 侧栏 ┐┌ 我的模型                          统计 ┐┌ Inspector 328 ┐
│      ││ 副标题                               ││ 封面 + 来源徽章 │
│      ││ 全部 / 中文站 / 国际站 / 本地模型     ││ 标题 / 副标题   │
│      ││                    排序   网格|列表  ││ 作者     分类   │
│      ││ 最近添加              显示 n / 总数  ││ 文件 大小 状态  │
│      ││ ┌卡片┐┌卡片┐┌卡片┐                 ││ 介绍|文件|归档   │
│      ││ └────┘└────┘└────┘                 ││ 编辑本地模型     │
│ 资料库││                                    ││ 在访达中显示     │
└──────┘└────────────────────────────────────┘└────────────────┘
```

**筛选（当前实现）：**

- 来源分段：全部、中文站、国际站、本地模型（与侧栏来源同步）
- 排序：最近添加、名称排序、文件大小
- 显示：网格 / 列表
- 搜索：名称、作者、材料；占位「搜索名称、作者或材料」

上一版还有作者、分类、下载状态筛选，本轮设计可以重新决定：保留进高级筛选，或收进 Inspector / 侧栏，避免工具区过挤。

**卡片（网格）：**

- 封面区固定高度约 132，图片等比放进框内，不撑高卡片
- 总高度固定，避免一行卡片高低不齐
- 选中：绿色描边
- 悬停：轻微上浮
- 已归档模型右下可有文字链「编辑」
- 右键：编辑本地模型
- 点击卡片：只选中，打开右侧 Inspector，不跳页

**列表行：** 缩略图、标题、作者、来源、大小、状态。

**右侧 Inspector：**

1. 大封面；多图时下方一排缩略图可切换  
2. 标题、副标题  
3. 作者头像字（姓首字母）、作者名、分类胶囊  
4. 三个指标：模型文件数、文件大小、本地状态（已归档 / 未下载）  
5. 分段：介绍 / 文件 / 归档  
   - 介绍：关于这个设计、摘要、材料、预估打印、打开来源页面  
   - 文件：每个文件一行（图标、文件名、格式）  
   - 归档：说明三点（模型文件、介绍、图片）+ 路径  
6. **底部固定操作条（不随介绍滚走）**
   - 已归档：主按钮「编辑本地模型」，次按钮「在访达中显示」
   - 未下载：主按钮「下载此模型」
   - 未选中：空状态「选择一个模型查看详情」

**空状态：**

- 库是空的：标题「模型库还是空的」；说明可从链接、用户主页或本地文件导入；按钮「导入模型」
- 筛选无结果：「没有符合条件的模型」

**加载：** 顶部小菊花；底部「加载更多（已显示 n / 总数）」

### 6.2 下载任务

**目标：** 看传输进度和失败，不替代模型库里的「已归档」。

**内容：**

- 标题「下载任务」；副标题「模型、介绍和展示图片会作为一个完整任务归档。」
- 四个指标：全部任务、等待完成、已完成、模型总大小
- 归档位置条：当前目录 +「修改」（跳到设置 · 存储）
- 队列标题 +「暂停全部」
- 每一行：封面、标题、阶段徽章、来源·作者、进度条、状态文案、暂停/继续/重试、取消

**阶段文案：** 等待中、下载中、已暂停、已完成、失败、已取消、部分完成

一个任务 = 模型文件 + 介绍 + 图片，不要拆成三条下载。

**空状态：** 「还没有下载任务」+「导入模型」

下载队列关闭应用后不必恢复（文件和模型库会保留）。界面不必画「上次未完成的幽灵队列」。

---

### 6.3 设置 · 站点账号

两张并排账号卡：MakerWorld 中文站（makerworld.com.cn）、MakerWorld 国际站（makerworld.com）。

每张卡：

- 站点标记、站点名、域名
- 状态胶囊：未连接 / 连接中 / 已连接 / 已过期 / 连接失败
- 已连接时显示用户名或 @handle
- 未连接时：「连接后可导入该站点的收藏」
- 按钮：未连接「打开登录页」；已连接「断开连接」

登录发生在 **系统独立窗口**（官网页面）。主窗口只表现「连接中」。用户在官网停在个人主页后，助手采集会话，主窗口变为已连接。

请设计账号卡五种状态，不要设计官网登录页。

---

### 6.4 设置 · 存储与下载

1. **本地存储**
   - 模型库位置（完整路径，可选择复制）
   - 按钮「选择目录」（系统文件夹选择器）
   - 未选目录、目录失效时的错误条
2. **下载偏好**
   - 完整归档：固定开启，文案「默认包含」，不可关掉介绍或图片
   - 首选文件格式：全部可用格式 / 优先 3MF / 优先 STL
   - 并行任务数：1 / 2 / 3 个任务
3. 页脚：「偏好自动保存在本机，无需再次点击保存。」

---

### 6.5 导入模型 Sheet（居中模态）

窗口建议宽度：远程导入约 760，本地模型约 940。圆角大卡片，背景遮罩。

**公共标题栏：**

- 关闭 ×  
- 小字 `NEW COLLECTION ITEM`  
- 大标题随步骤变化：添加模型 / 导入模型 / 确认你的归档清单  
- 本地模型时右侧：「取消」+ 主按钮「添加到模型库」

**来源分段（居中）：** 用户主页 | 模型链接 | 本地模型

#### A. 用户主页

- 来源站点：中文站 / 国际站  
- 目标用户：当前登录账号 / 指定用户（账号 / 作者）  
- 指定作者时：输入用户名、`@用户名`、用户 ID 或主页链接  
- 获取内容：当前账号可选收藏 / 发布；指定作者固定为公开发布模型  
- 主按钮「预览导入清单」  
- 未登录：提示条 +「连接中文站/国际站并继续」

对应关系：

- 当前账号 + 收藏 = 同步我的收藏  
- 指定作者 + 发布 = 导入作者公开作品  

#### B. 模型链接

- 输入框占位：`https://makerworld.com.cn/zh/models/…`  
- 自动识别中文站或国际站  
- 公开资料可先预览；真正下载 3MF 仍要已登录  

#### C. 清单预览（用户主页 / 链接共用）

- 说明条（已发现数量、不可访问原因等）  
- 「已选 n / 总数」；全选 / 清空  
- 每行：勾选、封面、标题、作者·站点；本地已有则提示「再次加入将覆盖更新」  
- 加载更多  
- 「返回修改」+「加入下载队列」  

#### D. 本地模型（新建）

双栏：

**左：表单**

- 模型名称 *  
- 作者（默认「我」）  
- 副标题  
- 分类  
- 模型文件 *：虚线拖放区，支持点按选择；可多选  
  格式：3MF、STL、OBJ、STEP、STP、GCODE、AMF  
- 已选文件列表：文件名、格式、移除  
- 展示图片：添加缩略图；第一张为封面，可「设为封面」、移除  
- 模型介绍（多行）  
- 更多打印资料（可折叠）：材料、预估打印时间  

**右：预览**

- 模型库预览卡片（与网格卡片同结构）  
- 「完整本地归档」说明  
- 保存位置路径  

底部辅助文案：原始文件只复制，不移动、不修改。未选归档目录时，引导「选择目录」。

主按钮在标题栏：「添加到模型库」。

---

### 6.6 编辑本地模型 Sheet

与新建共用同一套双栏表单，标题改为：

- 小字 `EDIT LOCAL MODEL`  
- 大标题「编辑本地模型」  
- 标题栏按钮：「取消」+「保存修改」

回填现有名称、作者、介绍、文件、图片。可追加/移除文件和图片、改封面。

保存后：模型 ID、归档路径、来源站点、在列表中的位置保持不变。  
**谁能编辑：** 凡是已经归档到本地的模型（自己创建的，以及已下载的站点模型）。未下载的站点模型没有编辑，只有「下载此模型」。

## 7. 用户流程（请画出这些箭头）

### 首次使用

1. 打开应用 → 空模型库  
2. 设置 → 存储 → 选择归档目录  
3. （可选）设置 → 打开登录页 → 在官网登录 → 回到应用显示已连接  
4. 导入模型  

### 从链接归档

导入 → 模型链接 → 粘贴 URL → 预览 → 勾选 → 加入下载队列 → 下载任务页 → 完成后出现在模型库 → 选中可看介绍 / 访达打开 / 编辑  

### 同步我的收藏

导入 → 用户主页 → 当前登录账号 → 收藏的模型 → 预览分页 → 加入队列  

### 添加自己的文件

导入 → 本地模型 → 拖入 3MF → 填名称和图片 → 添加到模型库 → 来源显示「本地模型」  

### 改一份已下载模型

模型库选中卡片 → Inspector「编辑本地模型」（或卡片「编辑」/ 右键）→ 改资料或换图 → 保存修改

## 8. 必须设计的状态

| 场景 | 界面表现 |
| --- | --- |
| 从未导入 | 空模型库 |
| 有数据 | 网格 + 默认选中第一项 + Inspector |
| 搜索/筛选为空 | 空结果，不要把整库清空成首次空状态 |
| 未选归档目录 | 导入/下载时提示去设置选目录 |
| 未登录就下 3MF | 提示连接对应站点，并提供「打开登录页」 |
| 登录中 | 账号卡「连接中」，主窗口仍可浏览本地库 |
| 登录过期 / 失败 | 账号卡状态 + 可再打开登录页 |
| 下载失败 / 部分完成 | 队列行红色或「部分完成」，可重试 |
| 图片缺失 | 卡片和 Inspector 用占位符，不崩布局 |
| 长标题、长路径 | 单行省略，路径可选择复制 |
| 深色模式 | 全套页面 |

## 10. 设计时请帮我们加强的点

当前程序能用，但视觉和层级希望这一轮重新想：

1. **模型库第一屏过挤** — 筛选、统计、卡片、Inspector 抢视线。希望更像 macOS 照片/音乐：工具少、封面大。  
2. **「编辑」不够显眼** — 已归档模型必须一眼能改资料和图片。  
3. **侧栏来源 vs 顶部分段** 功能重复，请合并成一套来源切换。  
4. **导入 Sheet 三种来源** 差异大（表单 / 链接 / 双栏本地），请统一标题栏和节奏，又让本地模型仍然好用。
