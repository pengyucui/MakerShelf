# MakerShelf 1.0

MakerShelf 1.0 是首个公开版本，提供原生 SwiftUI macOS 模型资料库，以及 MakerWorld 模型的本地归档流程。

## 主要功能

- 支持 MakerWorld 中文站与国际站。
- 导入当前账号收藏和发布模型。
- 按用户名、数字 UID 或作者主页链接读取公开发布模型。
- 下载模型文件，并归档介绍、作者信息和展示图片。
- 新建和编辑自己的本地模型。
- Native Glass 主界面、网格 / 列表浏览、搜索和筛选。

## 环境要求

- macOS 14 或更新版本
- Xcode 15 或更新版本（从源码运行）

## 安装

Release 附带由 GitHub Actions 重新构建的 `MakerShelf-1.0-unsigned-macOS.zip` 和 SHA-256 文件。当前自动构建没有 Developer ID 签名和 Apple 公证，macOS 可能阻止直接打开；熟悉源码构建的用户也可以下载源码后，用 Xcode 打开 `MakerShelf.xcodeproj` 运行。

## 已知限制

- MakerWorld 没有公开稳定的开发者 API，站点调整可能影响导入和下载。
- 当前账号收藏和模型文件下载需要在应用内完成对应站点登录。
- 付费、积分、地区和版权限制仍由 MakerWorld 决定，应用不会绕过。
- 下载任务暂不跨应用重启恢复。
